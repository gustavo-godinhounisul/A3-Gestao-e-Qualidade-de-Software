# Sistema de Gestão de Alunos 🎓

> **Status do Projeto:** 🚧 Em planejamento

Repositório destinado ao trabalho da disciplina de **Gestão e Qualidade de Software**. 

## 📝 Sobre o Projeto

Este projeto consiste no desenvolvimento de um **Sistema de Gestão de Alunos**, com foco não apenas na construção do software em si, mas na aplicação de práticas, normas e métricas de qualidade exigidas pela disciplina. O sistema visará facilitar o controle acadêmico, matrículas, notas e frequências, servindo como objeto de estudo para a implementação de processos de garantia de qualidade de software (SQA).
